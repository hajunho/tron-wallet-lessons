# 제작 기록

이 폴더는 자료를 **만든 과정**의 기록입니다. 레슨을 배우거나 가르치는 데는 필요하지 않습니다. 저장소를 고치거나 다른 체인으로 옮길 사람을 위한 문서입니다.

배우러 오셨다면 [START-HERE.md](../../START-HERE.md)로 가세요.

| 파일 | 읽어야 할 때 |
|------|--------------|
| [making-of.md](making-of.md) | 만든 순서와 결정, 남은 일, 다른 체인으로 옮기는 방법. **여기서 시작하세요** |
| [verified-facts.md](verified-facts.md) | 수치나 API가 맞는지 확인할 때. 이 자료의 모든 사실은 여기서만 나왔습니다 |
| [style-guide.md](style-guide.md) | 레슨을 새로 쓰거나 고칠 때. 8블록 구조, 분량 비율, 13규칙 원문, 스크립트 규약 |
| [lesson-specs.md](lesson-specs.md) | 각 레슨이 무엇을 다루기로 했는지 볼 때 |
| [review-log.md](review-log.md) | 어떤 오류가 있었고 어떻게 고쳤는지 볼 때 |

## 한 줄 요약

사실 확인(실제 실행) → 커리큘럼 3안 설계와 심사 → 레슨 집필 → 적대적 검수 208건 → 수정 → 클론 후 재검증 → 공개.

문서의 모든 출력과 수치는 실제 실행 결과입니다. 검증되지 않은 것은 `(확인 필요)`로 표시했습니다.
