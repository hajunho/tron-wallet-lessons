## 절대 규칙
1. 사실은 `tron-facts.md`에 있는 것만. 없는 API, 숫자, URL, 에러 문자열은 쓰지 않는다. 꼭 필요하면 "(확인 필요)"를 붙인다.
2. 실제 자산 절대 금지. 메인넷 URL을 코드 기본값으로 두지 않는다. 모든 전송 코드는 `lib/guard.js`의 `assertCanSend`를 브로드캐스트 직전에 호출한다. 기본은 미리보기(SEND_TX=false).
3. 작성자·검수자는 **어떤 경우에도 `SEND_TX=true`로 실행하지 않는다.** `.env` 파일을 만들지 않는다. 검증 실행은 `MNEMONIC="abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about"` 환경변수(데모)로만 한다.
4. 시세, 수익, 투자, "오를 것 같다" 같은 말은 어떤 대상 섹션에도 쓰지 않는다.
5. 개인키·니모닉은 `lib/print.js`의 `mask`/`maskMnemonic`으로만 출력한다. 데모 니모닉과 데모 주소(TUEZ…, TSeJ…)는 공개 값이라 그대로 써도 된다.
6. `lib/`, `tools/`, `package.json`, `.env.example`, `.gitignore`는 수정하지 않는다(필요한 헬퍼가 없으면 레슨 script.js 안에 지역 함수로 만든다).
7. 스크립트는 반드시 실행해 보고, 실제 출력을 `expected-output.txt`에 그대로 저장하고 README의 출력 예시도 그 출력에서 복사한다. 출력을 상상해서 쓰지 않는다.

## 세계관과 등장인물 (초등 섹션·비유에 일관되게 사용)
- **트론 마을**: 광장에 커다란 **장부**(블록체인)가 걸려 있고 **3초마다 새 장**이 붙는다. 장부지기(노드)가 아주 많아서 아무도 혼자 고칠 수 없다.
- **토리**: 초등학교 4학년, 호기심 많은 주인공. 이번에 처음 **보물상자**(지갑)가 생겼다. "~해요"체로 말한다.
- **노드 아저씨**: 광장의 장부지기. 규칙을 알려 주는 어른. **절대 열쇠(12단어)를 묻지 않는다.** 이 설정은 "고객센터도 니모닉을 묻지 않는다"의 근거로 매 레슨 활용.
- **비티**: 옆 나라 **BTTC**에서 온 로봇 강아지 친구. 레슨 2에서 "네 우편함 번호 안에 우리 나라 번호가 숨어 있어!"라고 예고하고, 레슨 11에서 회수한다.
- **여우 씨**: 사기꾼. 12단어를 물어보고, 가짜 서명 요청과 가짜 토큰을 보낸다. 안전 섹션에 등장. 폭력·공포 묘사 없이 "속임수"만.
- 비유 사전 (비유 이름 → 정식 용어). 처음 등장할 때 `비유 이름(정식 용어)`로 병기:
  - 12단어 주문(니모닉) / 열쇠(개인키) / 우편함 번호(주소, T로 시작) / 광장의 장부(블록체인) / 장부지기(노드)
  - 사탕(sun): 사탕상자 1개 = 사탕 100만 알 = 1 TRX
  - 입장권(자원): 종이 입장권(대역폭, 매일 600장 무료) / 기계 입장권(에너지, 무료 없음, TRX를 맡기면(스테이킹) 생김)
  - 봉투(트랜잭션) / 도장(서명) / 우체통에 넣기(브로드캐스트) / 영수증(receipt) / 발자국(이벤트 로그)
  - 허락증(approve/allowance) / 리허설(시뮬레이션) / 사탕통 장부(TRC-20 컨트랙트)
  - 연습 나라(테스트넷 Nile/Donau) vs 진짜 나라(메인넷). 연습 나라 돈은 진짜 돈이 아니다.
- 비유의 한계는 정직하게: 중고등 섹션 "원리 들여다보기"에서 비유가 틀리는 지점을 한 줄로 짚는다.

## 13대 안전 규칙 (레슨 제목과 1:1, 문장 그대로 사용)
1. 열쇠(12단어)는 나만 안다. 고객센터도 모른다.
2. 주소는 모두에게, 열쇠는 아무에게도.
3. 잔고는 앱이 아니라 장부(탐색기)에서 확인하고, 토큰은 이름이 아니라 컨트랙트 주소로 알아본다.
4. USDT만 있고 TRX가 0이면 아무것도 못 보낸다. 연료(입장권)가 먼저다.
5. 도장을 찍기 전에 봉투(트랜잭션 내용)를 끝까지 읽는다.
6. 보내면 되돌릴 수 없다. 처음 보내는 곳은 소액 먼저.
7. "보냈다"는 말 대신 txID로 영수증을 본다.
8. 무엇에 도장 찍는지 읽지 못하면 찍지 않는다.
9. 허락(approve)은 필요한 만큼만, 다 쓰면 0으로.
10. 앱이 "실패할 것 같다"고 하면 보내지 않는다.
11. 보내기 전에 나라(네트워크)를 상대와 글자까지 맞춘다.
12. 실패는 단서다. "고쳐 준다"는 사람은 사기다.
13. 한 달에 한 번 점검, 사고가 나면 순서대로, 혼자 끙끙대지 않기.

## script.js 규약
- 첫 줄 주석: `// Lesson NN — 제목 (실행: npm run lNN)`. 그 아래 3~6줄로 이 스크립트가 하는 일과 필요한 환경변수.
- `require('../../lib/wallet')`, `require('../../lib/tron')`, `require('../../lib/bttc')`, `require('../../lib/guard')`, `require('../../lib/print')`만 사용. 외부 패키지는 tronweb, ethers, bip39, dotenv(이미 lib에서 로드됨).
- 단계는 `print.step('제목')`으로, 값은 `print.info`, 성공/경고는 `print.ok`/`print.warn`. 각 단계 끝에 `print.explain({ kid, teen, dev, adult })` 한 줄(핵심 단계 3~5곳만).
- 읽기 전용 레슨(03, 04, 05, 07, 09, 10, 11, 12, 13)은 `.env`의 MNEMONIC이 없으면 **데모 니모닉으로 자동 대체**하고 "데모 모드" 안내를 출력한다. 레슨 06(실제 전송)은 MNEMONIC 없으면 안내 후 종료(exit 1).
- 기본 수신 주소(TO)는 같은 니모닉의 index 1 주소. 자기 자신에게 보내면 트론이 거부한다.
- 마지막에 `main().catch((error) => { console.error('lessonNN 실패:', errorMessage(error)); process.exitCode = 1; })`. 끝에 "➡️ 다음: Lesson NN+1 …" 한 줄.
- 네트워크 호출은 try/catch로 감싸고 실패 시 원인을 한국어로 안내(429는 "잠시 후 다시").
- 실행 시간 60초 이내. 폴링은 최대 30초.
