# 저학년 3차시 (1~3학년)

규칙 5개(1·2·6·8·13)만 축약해서 다룹니다. 코드 없음, 숫자는 3초·600장·100만 알 정도만. 한 차시 40분.

## 1차시 · 내 열쇠와 내 우편함 번호 (규칙 1, 규칙 2)

**목표**

- 12단어 주문을 아는 사람은 누구든 똑같은 열쇠를 만들 수 있다는 것을 안다.
- 우편함 번호는 모두에게 알려 줘도 되고, 열쇠는 아무에게도 알려 주지 않는다고 말할 수 있다.

**이야기** — [Lesson 01 이야기](../../lessons/01-secret-key/README.md#story), [Lesson 02 이야기](../../lessons/02-key-to-address/README.md#story)

바이블 씨앗 그대로 읽어 줍니다.
- 01: "토리가 보물상자 열쇠를 자꾸 잃어버려요. 노드 아저씨가 주사위를 12번 굴려 12단어 주문(니모닉)을 만들어 줘요. 주문을 아는 사람은 누구든 똑같은 열쇠를 깎을 수 있어요."
- 02: "토리가 열쇠를 특별한 기계(해시)에 넣으니 T로 시작하는 우편함 번호가 나와요. 반대로 번호를 넣어도 열쇠는 안 나와요."
- 예고 심기: 비티의 대사 "토리! 네 우편함 번호 안에 우리 나라 번호가 숨어 있어!" 를 그대로 들려주고, "이 비밀은 나중에 풀려요"까지만 말합니다(저학년은 회수하지 않습니다).

**활동** — [Lesson 01 활동지](../../lessons/01-secret-key/activity.md) "주사위로 12단어 주문 카드 만들기" + [Lesson 02 활동지](../../lessons/02-key-to-address/activity.md) "색깔 믹서"

- 주사위를 굴려 단어표에서 단어를 골라 주문 카드를 채웁니다. 저학년은 주사위 1인당 2개로 충분합니다.
- 다 쓴 주문 카드는 **접어서 봉투에 넣고 자기 이름만 겉에 씁니다.** 서로 보여 주지 않는 것이 이 차시의 핵심 규칙입니다.
- 색깔 믹서: 같은 색 순서를 넣으면 같은 색 띠가 나오고, 색 하나만 바꾸면 띠가 통째로 달라지는 것을 눈으로 봅니다.
- (교사 시연, 오프라인) `npm run l01` → `npm run l02`. 각 0.3초면 끝납니다. `[5]` 단계의 T주소가 두 번 실행해도 같은지, 주사위 눈 하나를 바꾸면 주소가 통째로 바뀌는지만 보여 줍니다.

**확인 질문**

1. 노드 아저씨가 토리에게 **하지 않은** 일은? ① 주사위 굴리기 ② 단어 고르는 법 알려 주기 ③ 주문이 뭐냐고 물어보기
2. 친구에게 알려 줘도 되는 것은 열쇠일까요, 우편함 번호일까요?
3. 색 하나만 바꿨는데 색깔 띠가 전부 바뀌었어요. 우편함 번호도 그럴까요?

**준비물** — 주사위 1인당 2개, 한국어 단어표(활동지 워크시트 A) 모둠당 1장, 주문 카드(워크시트 B) 1인 1장, 접어 넣을 봉투, 색연필 8색(빨강·주황·노랑·초록·파랑·남색·보라·검정) 모둠당 1세트, 색깔 띠 워크시트 1인 1장, 여우 씨 이름표 1개.

**시간 배분** (40분) — 이야기 8분 / 주문 카드 만들기 12분 / 색깔 믹서 10분 / 교사 시연 5분 / 확인 질문 5분

## 2차시 · 보내면 되돌릴 수 없어요 (규칙 6)

**목표**

- 우체통에 넣은 편지는 되돌릴 수 없다는 것을 몸으로 겪는다.
- 처음 보내는 곳에는 아주 조금만 먼저 보낸다고 말할 수 있다.

**이야기** — [Lesson 06 이야기](../../lessons/06-send-testnet/README.md#story)

바이블 씨앗: "토리가 도장 찍은 봉투를 연습 나라 우체통에 넣어요. 3초 뒤 장부지기들이 새 장에 적어요. 토리가 '아, 사탕 수 잘못 썼다!' 하지만 지우개가 없어요. 노드 아저씨는 '그래서 처음 보내는 친구에겐 사탕 1알 먼저'라고 해요."

**활동** — [Lesson 06 활동지](../../lessons/06-send-testnet/activity.md) "되돌릴 수 없는 편지" 역할극 (4~6명 한 모둠)

- 손이 들어가지 않게 입구를 좁힌 상자를 "우체통"으로 씁니다. 한 번 넣으면 진행자도 꺼내 주지 않습니다.
- 장부지기 3명이 큰 종이에 **각자** 적습니다. 세 사람의 장부가 똑같은지 맞춰 봅니다.
- "하나, 둘, 셋" 구령으로 3초마다 새 장을 붙입니다.
- 일부러 사탕 수를 잘못 쓴 봉투를 하나 넣어 보고, 지우개가 없다는 것을 확인합니다. 그다음 "사탕 1알 먼저" 봉투를 만들어 넣습니다.

**확인 질문**

1. 우체통에 넣은 편지를 다시 꺼낼 수 있나요?
2. 장부지기가 세 명인데 왜 세 사람이 다 적나요?
3. 처음 편지를 보내는 친구에게는 사탕을 몇 알 보내면 좋을까요?

**준비물** — 봉투 워크시트 모둠당 6장, 입구가 좁은 상자 1개(우체통), 스티커나 도장, 구슬·콩·바둑돌 30개(사탕), 큰 종이 1장과 마커 3개(장부지기 3명이 각자 씀), 초시계 또는 구령.

**시간 배분** (40분) — 이야기 8분 / 역할 정하기 5분 / 역할극 18분 / 확인 질문과 정리 9분

> 교사 메모: 이 차시에서 스크립트 시연은 하지 않습니다. `npm run l06`은 `MNEMONIC` 환경변수가 있어야 진행되고, 보내는 내용을 다루기 때문에 저학년에게는 역할극만으로 충분합니다.

## 3차시 · 읽지 못하면 도장 안 찍어요, 그리고 점검 (규칙 8, 규칙 13)

**목표**

- 무엇에 도장을 찍는지 읽지 못하면 찍지 않는다고 말할 수 있다.
- 한 달에 한 번 점검하고, 이상하면 어른에게 바로 말한다는 습관을 정한다.

**이야기** — [Lesson 08 이야기](../../lessons/08-sign-message/README.md#story), [Lesson 13 이야기](../../lessons/13-audit-and-graduation/README.md#story)

바이블 씨앗 그대로.
- 08: "비티가 '네가 진짜 토리인지 증명해 봐' 해요. 토리는 그냥 종이에 '나는 토리예요'라고 쓰고 도장을 찍어요. 우표는 안 들어요. 여우 씨가 아무것도 안 적힌 종이를 내밀며 '여기도 찍어 줘' 해요. 토리는 안 찍어요."
- 13: "한 달에 한 번, 토리가 부모님과 보물상자를 점검해요. 문제가 생기면 새 상자 만들기부터 순서대로 해요."

**활동** — [Lesson 08 활동지](../../lessons/08-sign-message/activity.md) "도장 검증 놀이" + [Lesson 13 활동지](../../lessons/13-audit-and-graduation/activity.md) "보물상자 점검표와 졸업장"

- 각자 자기 도장 무늬를 그립니다(색 2개 + 모양 1개, 예: 빨강 세모 + 파랑 점).
- 메시지 카드를 돌려 가며 도장을 찍고, 누구 도장인지 맞힙니다. 그러면서 여우 씨(진행자)가 **빈 카드 2장**을 섞어 넣습니다. 빈 카드에 도장을 찍은 사람이 있으면 함께 이야기합니다 — 혼내지 않고 "그래서 미리 이렇게 해요"로 넘어갑니다.
- 점검표: 큰 종이에 "토리의 상자" 네 칸을 그리고, 상황 카드 A(정상)와 B("열쇠 구멍 주인이 여우 씨")를 보여 주며 어느 칸이 이상한지 색연필로 표시합니다. 저학년은 카드 A와 B 두 장만 씁니다.
- 마지막에 졸업장을 씁니다. 규칙 5개(1·2·6·8·13)를 한 줄씩 따라 씁니다.
- (교사 시연, 오프라인) `npm run l08`. 0.2초면 끝납니다. "종이에 도장을 찍었는데 우표(수수료)가 0"이라는 줄만 짚어 줍니다.

**확인 질문**

1. 여우 씨가 빈 종이를 내밀며 "여기 도장 찍어 줘" 하면 어떻게 하나요?
2. 종이에 도장을 찍는 데에는 우표가 드나요, 안 드나요?
3. 점검을 하다가 이상한 칸을 찾으면 누구에게 먼저 말하나요?

**준비물** — 도장 카드 1인 1장, 메시지 카드 12장(활동지 워크시트 2를 오림), 빈 카드 2장(여우 씨용), 색연필, 가위, 점검표 워크시트 1인 1장, 졸업장 양식 1인 1장, 초록·주황 색연필, 큰 종이 1장, 상황 카드 A·B.

**시간 배분** (40분) — 이야기 8분 / 도장 검증 놀이 14분 / 점검표 8분 / 교사 시연 3분 / 졸업장과 확인 질문 7분

## 1차시 · Lesson 01 — 12개 단어로 만든 비밀 열쇠

- **규칙 1**: 열쇠(12단어)는 나만 안다. 고객센터도 모른다.
- **목표**: 아무도 못 맞히는 무작위에서 12단어가 나오고, 12단어에서 열쇠가 나오는 순서를 말할 수 있다. 12단어를 묻는 사람은 누구든 사기라고 판단할 수 있다.
- **이야기** — [#story](../../lessons/01-secret-key/README.md#story). 씨앗: "노드 아저씨가 주사위를 12번 굴려 12단어 주문(니모닉)을 만들어 줘요. 주문을 아는 사람은 누구든 똑같은 열쇠를 깎을 수 있어요." 핵심 문장은 규칙 1 그대로.
- **활동** — [activity.md](../../lessons/01-secret-key/activity.md) "주사위로 12단어 주문 카드 만들기"(25~30분). 고학년은 주사위 1인당 4개. 워크시트 D "가짓수 세어 보기" 빈칸까지 채웁니다.
- **교사 시연** (오프라인, 0.3초) — `npm run l01`. `DICE="…"`를 똑같이 주고 두 번 실행해 `[5]`의 T주소가 같은지, 눈 하나만 바꾸면 주소가 통째로 바뀌는지 보여 줍니다.
- **확인 질문**: ① 노드 아저씨가 하지 않은 일은? ② 12단어를 잃어버리면 누가 다시 만들어 주나요? ③ 사진첩에 12단어를 찍어 두면 왜 안 되나요?
- **준비물**: 주사위 1인당 4개, 단어표(워크시트 A) 모둠당 1장, 주문 카드(워크시트 B) 1인 1장, 여우 씨 대사 카드(워크시트 C), 봉투, 연필.

## 2차시 · Lesson 02 — 열쇠에서 우편함 번호가 나와요

- **규칙 2**: 주소는 모두에게, 열쇠는 아무에게도.
- **목표**: 열쇠 → 번호 방향으로만 갈 수 있고 거꾸로는 갈 수 없다는 것을 설명할 수 있다. T로 시작하는 34글자를 알아본다.
- **이야기** — [#story](../../lessons/02-key-to-address/README.md#story). 비티의 예고 "네 우편함 번호 안에 우리 나라 번호가 숨어 있어!"를 꼭 읽어 줍니다(11차시에서 회수).
- **활동** — [activity.md](../../lessons/02-key-to-address/activity.md) "색깔 믹서"(25~30분). 워크시트 A 규칙표로 이름을 색 띠로 바꾸고, 옆 사람 띠만 보고 이름을 되맞혀 봅니다(안 됩니다 — 그게 핵심).

- **확인 질문**: ① 트론 마을 번호와 옆 나라 번호는 앞글자가 어떻게 다른가요? ② 열쇠는 몇 개인가요? ③ 봉투에 나라 이름을 안 쓰면 어떻게 되나요?
- **준비물**: 나라 카드 3장, 우편함 번호 카드 12장, 옆 나라 봉투 워크시트 모둠당 4장, 색연필 2색, 열쇠 모양 종이 1장.

## 12차시 · Lesson 12 — 실패 탐정: 왜 안 됐을까?

- **규칙 12**: 실패는 단서다. "고쳐 준다"는 사람은 사기다.
- **목표**: 반송 도장을 읽고 원인을 스스로 찾는다. "고쳐 줄게, 열쇠 줘"는 사기라고 말한다.
- **이야기** — [#story](../../lessons/12-error-detective/README.md#story). 6차시의 "지우개가 없어요"가 여기서 회수되고, 여우 씨의 "내가 고쳐 줄게, 열쇠 줘"는 13차시 사고 대응 순서로 이어집니다.
- **활동** — [activity.md](../../lessons/12-error-detective/activity.md) "반송 도장 탐정"(25~30분). 반송 도장 카드 9장과 원인 카드 9장을 짝 맞춥니다. 파랑(사건 1·2·5)은 내 컴퓨터가 찍은 도장, 빨강(사건 3·4·6·7·8·9)은 광장 장부지기·자판기가 찍는 도장으로 색을 나눕니다.
- **교사 시연** (네트워크 필요, 3.5초) — `CASE=1 npm run l12`부터 `CASE=9`까지 하나씩. 화면의 "단서" 줄과 카드를 대조합니다. 사건 3은 봉투를 다 만들고도 우체통 앞 관문에서 멈추므로, 자산은 한 번도 움직이지 않습니다.
- **확인 질문**: ① 반송 도장은 누가 찍나요? 두 가지가 있어요. ② "고쳐 줄게, 열쇠 줘"는 누구 말인가요? ③ 실패한 편지는 되돌려 받을 수 있나요?
- **준비물**: 반송 도장 카드 9장·원인 카드 9장(모둠 수만큼 인쇄해 자름), 탐정 수첩 워크시트 1인 1장, 연필, 색연필 2색(파랑·빨강), (있으면) 컴퓨터 1대.

## 13차시 · Lesson 13 — 내 지갑 점검과 졸업

- **규칙 13**: 한 달에 한 번 점검, 사고가 나면 순서대로, 혼자 끙끙대지 않기.
- **목표**: 점검 네 칸(사탕 수·허락증·최근 편지·열쇠 구멍 주인)을 스스로 채운다. 사고 대응 순서를 번호로 적는다.
- **이야기** — [#story](../../lessons/13-audit-and-graduation/README.md#story). **3차시 노드 아저씨의 예고를 여기서 회수합니다** — "열쇠 구멍 주인이 다른 상자"가 왜 그렇게 됐는지 알게 됩니다. 1차시의 "주문을 아는 사람은 열쇠를 똑같이 깎을 수 있어"도 여기서 닫힙니다.
- **활동** — [activity.md](../../lessons/13-audit-and-graduation/activity.md) "보물상자 점검표와 졸업장"(30분). 상황 카드 A(정상)·B(열쇠 구멍 주인이 여우 씨)·C(허락증 빈칸)를 보고 ✅/⚠️를 초록·주황으로 표시합니다. 마지막에 13개 규칙을 한 줄씩 따라 쓴 졸업장을 완성합니다.
- **교사 시연** (네트워크 필요, 4.0초) — `npm run l13`. `[4]` 단계의 허락증 확인, 그리고 권한 키가 계정 자신이 아닌 줄을 짚습니다. 탐색기 <https://nile.tronscan.org/#/address/TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH> 에서 "주인이 다른 상자"를 함께 봅니다.
- **확인 질문**: ① 점검은 얼마에 한 번 하나요? ② 열쇠 구멍 주인이 내가 아니면 무슨 일이 일어난 건가요? ③ 이상한 일이 생기면 누구에게 먼저 말하나요?
- **준비물**: 점검표 워크시트 1인 1장, 졸업장 양식 1인 1장, 색연필 2색(초록·주황), 칠판 또는 전지 1장, 상황 카드 4장(교사가 미리 적음).
