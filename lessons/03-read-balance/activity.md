# Lesson 03 활동: 사탕 세기 카드와 칠판 장부

규칙 3: 잔고는 앱이 아니라 장부(탐색기)에서 확인하고, 토큰은 이름이 아니라 컨트랙트 주소로 알아본다.

대상: 초등 3~6학년(중고등은 "확장" 항목 추가). 시간: 25분. 장비 없이도 가능(아래 "무장비 5분 버전").

## 준비물

- 칠판 또는 전지 1장 ("광장 장부")
- 인쇄용 워크시트(아래) 학생 수만큼
- 이름표 5~6개
- 색이 다른 스티커 또는 색종이 2종 (사탕통 카드용)
- 사탕통 카드 2장: 둘 다 겉에 "USDT"라고 크게 쓰고, 아래에 작은 글씨로 번호를 다르게 쓴다.
  - 진짜: `TXYZopYRdj2D9XRtbG411XZZ3kM5VkAeBf`
  - 가짜: 교사가 임의로 만든 T로 시작하는 34글자 (앞 4글자 `TXYZ`만 같게 하면 더 좋다)

## 진행 (25분)

1. **장부 걸기 (5분).** 교사가 칠판 맨 위에 "광장 장부 — 1장"이라고 쓰고, 학생 다섯 명의 이름과 사탕 알 수를 적는다. 예: 토리 2,500,000알, 비티 1,000,000알, 민지 250,000알, 준호 3,000,000알, 하나 500,000알. "이 장부는 누가 볼 수 있을까요?" → 반 전체.
2. **사탕 세기 카드 (7분).** 학생은 워크시트 1번 표를 채운다. 규칙은 하나: **사탕상자 1개 = 사탕 100만 알.** 알 수를 상자 수로, 상자 수를 알 수로 바꾼다. 소수점이 왼쪽으로 여섯 칸 가는 것을 손가락으로 세어 본다.
3. **새 장 붙이기 (5분).** 교사가 "3초 뒤 새 장!" 하고 외치면 "광장 장부 — 2장"을 아래에 새로 그리고, 사탕이 오간 기록 한 줄을 적는다. 예: "토리 → 민지 500,000알". 그리고 1장의 숫자를 지우려는 시늉을 한다. 학생들이 "지우개 없음!"을 외치면 멈춘다. 2장에 바뀐 알 수를 새로 적는다(1장은 그대로 남긴다).
4. **가짜 사탕통 찾기 (5분).** 학생 두 명이 사탕통 카드를 하나씩 들고 나와 "이거 진짜 USDT 사탕통이야!"라고 말한다. 반 전체가 카드를 돌려 보고 워크시트 3번을 채운다. 결론은 항상 같다. **이름은 같아도 번호가 다르면 다른 사탕통.**
5. **마무리 (3분).** 워크시트 4번에 "내 사탕은 앱에 있나요, 장부에 있나요?"의 답을 한 줄로 쓰고, 두 명이 발표한다.

**중고등 확장(10분):** 워크시트 1번의 숫자를 sun/TRX로 바꿔 부르고, `55,167,408,590 sun`을 TRX로 계산한다(답 55,167.40859). 그다음 교사 컴퓨터에서 `npm run l03`을 실행해 `[2]`의 두 줄과 답이 같은지 확인한다.

### 발문 3개

1. 앱을 지우거나 휴대폰을 잃어버리면 토리의 사탕은 사라질까요? 사탕은 어디에 적혀 있나요?
2. 사탕 250만 알은 상자로 몇 개일까요? 사탕상자 0.5개는 몇 알일까요?
3. 여우 씨의 사탕통은 이름이 "USDT"였어요. 그래도 가짜라고 말할 수 있는 이유는 무엇인가요?

## 무장비 5분 버전

칠판만 있으면 된다. 교사가 이름 다섯 개와 알 수를 적는다(1,000,000 / 250,000 / 3,000,000 / 500,000 / 2,000,000). 학생들은 "상자로는?"에 입으로 답한다(1 / 0.25 / 3 / 0.5 / 2). 교사가 한 줄을 지우려 하면 반 전체가 "지우개 없음!"을 외친다. 마지막으로 교사가 "USDT"라고 쓴 종이 두 장을 들고 아래 번호가 다른 것을 보여 준다. "이름이 같아도 번호가 다르면?" → "다른 사탕통!" 끝.
