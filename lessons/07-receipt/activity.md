# Lesson 07 활동지 — 영수증 읽기

규칙 7: "보냈다"는 말 대신 txID로 영수증을 본다.

---

## 활동 1. 우체국 영수증 읽기 (교실, 20~30분)

### 준비물
- 아래 "인쇄용 워크시트"를 학생 수만큼 인쇄 (A4 1장)
- 교사용 영수증 카드 3장 (아래 "교사용 영수증 카드"를 잘라서 사용)
- 연필, 색연필(성공은 파랑, 실패는 빨강)
- (있으면) 컴퓨터 1대: `npm run l07` 을 실행한 화면 또는 `expected-output.txt` 를 크게 띄움

### 진행
1. **상황 제시 (3분)** — 교사가 토리 역할: "친구가 '사탕 보냈어!' 하고 말만 해요. 정말 보냈는지 어떻게 알까요?" 학생들의 답을 칠판에 적습니다. ("믿어요", "사진 보여 달라고 해요", "장부를 봐요" 등)
2. **봉투 번호 소개 (3분)** — 레슨 5에서 만든 봉투 번호(txID)를 떠올립니다. "봉투 번호만 있으면 광장 장부에서 누구나 영수증을 찾을 수 있어요." 교사용 영수증 카드 1번을 보여 주며 각 칸의 이름을 읽습니다: 몇 번째 장(blockNumber), 시각(blockTimeStamp), 요금(fee), 결과(result), 발자국(log).
3. **영수증 채우기 (10분)** — 교사용 영수증 카드 2번(성공, 발자국 있음)과 3번(실패)을 칠판에 붙입니다. 학생은 워크시트 표에 두 영수증의 값을 옮겨 적고, 결과 칸을 색칠합니다(성공 파랑, 실패 빨강).
4. **발자국 추적 (7분)** — 카드 2번의 발자국(누가 → 누구에게 → 몇 알)을 화살표 그림으로 그립니다. "발자국은 자판기(컨트랙트)를 쓴 봉투에만 남아요. 카드 3번에는 왜 발자국이 없을까요?"
5. **정리 (3분)** — 워크시트 맨 아래 빈칸 문장을 완성합니다: "'보냈다'는 말 대신 ______로 ______을 본다."

### 발문 3개
1. 친구가 "보냈어!"라고 말한 것과 영수증에 "SUCCESS"가 찍힌 것은 무엇이 다른가요?
2. 영수증에 요금(fee)은 찍혔는데 결과가 "REVERT(실패)"예요. 사탕은 갔을까요? 요금은 냈을까요?
3. 발자국(log)이 하나도 없는 영수증이 있어요. 이 봉투는 어떤 편지였을까요?

## 무장비 5분 버전 — 영수증 소리 내어 읽기

교실에 컴퓨터가 없어도 됩니다. 교사가 아래 영수증을 칠판에 적거나 말로 읽어 주고, 학생이 한 줄씩 따라 읽으며 뜻을 말합니다.

> 영수증 — 몇 번째 장: 70892020 / 시각: 16시 29분 3초 / 요금: 사탕 701,000알 (0.701 상자) / 결과: SUCCESS / 발자국: 3개 (첫 발자국: TF5n… → TCET… 사탕통 장부의 사탕 0.3개)

진행: ① 교사가 "몇 번째 장?" 하면 학생이 "70892020!" ② "요금?" → "0.701 상자!" ③ "결과?" → "성공!" ④ "발자국?" → "3개, 첫 발자국은 TF5n에서 TCET로 사탕통 장부의 사탕 0.3개!" ⑤ 마지막으로 다 같이 "보냈다는 말 대신, 영수증을 본다!"

변형: 교사가 "결과: REVERT"로 바꿔 읽으면 학생이 "사탕은 안 갔어요, 요금은 냈어요!"라고 답합니다.

## 교사용 영수증 카드 (잘라서 사용)

값은 이 레슨의 `expected-output.txt`(2026-09-12 Nile 실행)에서 가져온 실제 값입니다. 카드 3번은 결과만 "REVERT"로 바꾼 가상의 예시입니다.

```
┌─ 영수증 카드 1 (읽는 법) ──────────────────────────┐
│ 봉투 번호(txID): dd46b445…c8bd8 (64글자)           │
│ 몇 번째 장(blockNumber): 70892020                  │
│ 시각(blockTimeStamp): 2026. 9. 12. 16:29:03 (KST)  │
│ 요금(fee): 701000 sun = 0.701 TRX                  │
│ 결과(result): SUCCESS                              │
│ 발자국(log): 3개                                   │
└────────────────────────────────────────────────────┘

┌─ 영수증 카드 2 (성공 + 발자국) ────────────────────┐
│ 몇 번째 장: 70892020        결과: SUCCESS           │
│ 종이 입장권 요금(net_fee): 701000 sun               │
│ 기계 입장권 요금(energy_fee): 0 sun                 │
│ 발자국 3개 (첫 번째만 적음): Transfer, USDT         │
│   from TF5n96auHbEcTrR5GmY1Qm9XXMbjPe22y9           │
│   to   TCETRh3aED4kdkaYQY7CcxeTJtrQvwBpNT           │
│   value 300000 (raw) = 0.3 USDT (decimals 6)        │
└────────────────────────────────────────────────────┘

┌─ 영수증 카드 3 (실패 예시 — 가상) ─────────────────┐
│ 몇 번째 장: (칠판에 아무 수)   결과: REVERT         │
│ 요금(fee): (0이 아닌 수)                            │
│ 발자국: 0개                                         │
│ → 사탕은 안 갔지만 요금은 나갔어요.                 │
└────────────────────────────────────────────────────┘
```

## 인쇄용 워크시트 — "영수증 탐정" (A4 1장)

이름: ______________   날짜: ____________

### 1. 영수증 옮겨 적기

| 칸 이름 | 정식 용어 | 영수증 카드 2 | 영수증 카드 3 |
|---|---|---|---|
| 몇 번째 장 | blockNumber | | |
| 시각 | blockTimeStamp | | |
| 종이 입장권 요금 | net_fee (sun) | | |
| 기계 입장권 요금 | energy_fee (sun) | | |
| 요금 전체 | fee (sun) | | |
| 결과 (색칠: 성공 파랑 / 실패 빨강) | result | ☐ | ☐ |
| 발자국 수 | log 개수 | | |

### 2. 발자국 그리기 (카드 2)

```
   ┌─────────────┐        사탕 ______ 알(raw)        ┌─────────────┐
   │ from        │  ───────────────────────────────▶ │ to          │
   │ ___________ │                                   │ ___________ │
   └─────────────┘                                   └─────────────┘
```

### 3. 계산해 보기

- 요금 전체(fee) = 종이 입장권 요금(net_fee) + 기계 입장권 요금(energy_fee)
- 카드 2: ________ + ________ = ________ sun
- sun을 TRX(사탕상자)로: ________ sun ÷ 1,000,000 = ________ TRX

### 4. 맞으면 O, 틀리면 X

| 문장 | O / X |
|---|---|
| 친구가 "보냈어"라고 말하면 사탕이 온 것이다. | |
| 봉투 번호(txID)만 있으면 누구나 영수증을 찾을 수 있다. | |
| 결과가 REVERT면 요금도 안 낸다. | |
| 발자국(log)은 자판기(컨트랙트)를 쓴 봉투에만 남는다. | |
| 영수증은 봉투를 넣자마자 바로 나온다. | |

### 5. 빈칸 채우기

"보냈다"는 말 대신 __________로 __________을 본다.

## 워크시트 정답 (교사용)

- 1번 표 카드 2: 70892020 / 2026. 9. 12. 16:29:03 / 701000 / 0 / 701000 / SUCCESS(파랑) / 3
