# Lesson 13 활동: 보물상자 점검표와 졸업장

규칙 13: 한 달에 한 번 점검, 사고가 나면 순서대로, 혼자 끙끙대지 않기.

대상: 초등 3~6학년(중고등은 "확장" 항목 추가). 시간: 30분. 장비 없이도 가능(아래 "무장비 5분 버전").

## 준비물

- 인쇄용 점검표 워크시트(아래) 학생 수만큼
- 졸업장 양식(아래) 학생 수만큼
- 색연필 2색: 초록(✅) / 주황(⚠️)
- 칠판 또는 전지 1장 ("토리의 상자" 네 칸을 그린다)
- 상황 카드 4장: 교사가 미리 적어 둔다.
  - 카드 A: "사탕상자 55개, 허락증 0, 최근 편지 5장 모두 토리가 보냄, 열쇠 구멍 주인 토리" (정상)
  - 카드 B: "열쇠 구멍 주인이 **여우 씨**" (⚠️ 권한)
  - 카드 C: "허락증 칸에 **숫자가 없음(빈칸)**" (⚠️ 무제한 허락)
  - 카드 D: "토리가 **보낸** 편지 한 장을 토리가 기억하지 못함" (⚠️ 내가 보낸 기억 없는 거래. 받은 편지는 ⚠️가 아니다)
- 사고 대응 카드 5장(순서 섞어서): "멈추기" / "새 상자 만들기" / "사탕 옮기기(사탕상자 먼저, 조금만)" / "허락증 거두기(0으로)" / "어른에게 알리기·신고"
- 13규칙 카드 13장: 앞면에 번호, 뒷면에 규칙 문장 전체(README 안전 규칙 카드 또는 `expected-output.txt`의 졸업 체크리스트에서 그대로 복사)

## 진행 (30분)

1. **점검표 채우기 (7분).** 교사가 칠판에 "토리의 상자"를 그리고 네 칸(사탕 수 / 허락증 / 최근 편지 / 열쇠 구멍 주인)에 카드 A의 값을 적는다. 학생은 워크시트 1번 표에 값을 옮겨 적고 ✅ 칸을 초록으로 칠한다. "네 칸이 다 초록이면 이번 달 점검 끝!"
2. **몰래 바꾼 칸 찾기 (8분).** 교사가 학생들이 눈을 감은 사이 카드 B·C·D 중 하나로 칸 하나를 바꾼다. 눈을 뜬 학생들은 어느 칸이 ⚠️인지 찾아 주황으로 칠하고, 워크시트 2번에 "어느 규칙 번호"인지 적는다(B → 규칙 1·13, C → 규칙 9, D → 규칙 7·13). 세 번 반복한다.
3. **사고 대응 줄 세우기 (7분).** ⚠️가 나올 때마다 다섯 명이 사고 대응 카드를 한 장씩 들고 앞에 나와 순서대로 선다. 반 전체가 "멈추기 → 새 상자 → 사탕 옮기기 → 허락증 거두기 → 어른에게"를 읽으며 확인한다. 순서가 틀리면 처음부터. 교사는 "여우 씨가 '내가 고쳐 줄게, 열쇠 줘'라고 하면?" 하고 묻고, 학생들은 "1번 멈추기! 여우 씨 말 안 들어요!"로 답한다.
4. **13규칙 뽑기 (6분).** 13규칙 카드를 번호가 보이게 펼친다. 학생이 한 장 뽑아 번호를 보고 규칙 문장을 끝까지 말한다. 막히면 뒷면을 보고 따라 읽은 뒤 다시 뒤집는다. 반 전체가 13장을 모두 한 번씩 말하면 통과.
5. **졸업장과 다음 점검일 (2분).** 워크시트 3번 졸업장에 이름을 쓰고, 4번 "다음 점검일"에 오늘부터 한 달 뒤 날짜를 적는다. "혼자 끙끙대지 않기"에 함께 점검할 사람 이름을 적는다.

**중고등 확장(10분):** 교사 컴퓨터에서 `npm run l13`을 실행한다. `[2]`의 `owner 키 #1: 41156f…` 와 `내 hex 주소: 41c859…` 를 학생이 앞 6글자로 비교하고, `[6]`의 `점검 항목: 9개 — ✅ 7개 / ⚠️ 2개 / ❓ 0개`를 워크시트 5번에 옮겨 적는다. 그다음 `npm run l13 -- TSeJkUh4Qv67VNFwY8LaAxERygNdy6NQZK`로 두 번째 주소를 점검해 owner 키가 **같은 값**인지 확인하고, "같은 사람이 두 상자를 다 가져갔다"는 결론을 한 줄로 쓴다.

### 발문 3개

1. 한 달에 한 번 점검할 네 가지는 무엇인가요? 그중 앱 첫 화면에 안 보이는 것은 무엇인가요?
2. 열쇠 구멍 주인이 여우 씨로 바뀐 상자에 사탕을 더 넣으면 어떻게 될까요? 그 상자를 고칠 수 있나요, 새로 만들어야 하나요?
3. 사고 대응 다섯 순서 중에서 "어른에게 알리기"가 마지막에 있어요. 그런데 왜 실제로는 처음부터 어른과 같이 해야 할까요?

## 무장비 5분 버전

칠판도 인쇄물도 필요 없다. 교사가 "규칙 하나!" 하고 외치면 반 전체가 "열쇠는 나만 안다, 고객센터도 모른다!"를 외친다. "규칙 둘!" → "주소는 모두에게, 열쇠는 아무에게도!" 이렇게 13까지 간다. 막히는 번호가 나오면 교사가 그 레슨 제목만 힌트로 준다(예: 9번 → "사탕통 장부와 허락증"). 다 끝나면 교사가 "사고 나면?" 하고 묻고, 학생들은 손가락을 하나씩 꼽으며 "멈추고, 새 상자, 사탕 옮기고, 허락 거두고, 어른에게!"를 외친다. 두 번 반복하면 5분이다.
