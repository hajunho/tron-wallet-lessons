[2] 메시지 서명 (signMessageV2) 과 검증 (verifyMessageV2)
  메시지: "나는 토리예요"
  메시지 바이트 길이(UTF-8): 19
  서명: 0x7a852d98…fc66f81b (0x + 130 hex, 65바이트)
  복원된 주소: TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH
  내 주소와 비교: MATCH
  ✅ 같은 메시지 + 같은 서명 → 내 주소가 복원됩니다.
  바꾼 메시지: "나는 토리예!"
  바꾼 메시지로 복원된 주소: TB18AarnHDJa9v7jvrVo1vzCgwztzyCP34
  내 주소와 비교: MISMATCH
  ⚠️  verifyMessageV2 는 틀려도 예외를 던지지 않고 "다른 주소"를 돌려줍니다. 검증 = "복원 주소 == 기대 주소" 비교입니다.
  💬 형식이 올바른 서명이면 어떤 digest 에도 주소를 돌려준다. 반드시 expected 와 === 비교.

[3] 프리픽스 직접 계산: 같은 키라도 프리픽스가 다르면 다른 서명
  트론 프리픽스: "\u0019TRON Signed Message:\n"
  이더리움 프리픽스: "\u0019Ethereum Signed Message:\n"
  keccak256(트론 프리픽스 + 길이 + 메시지): 0xbc772be197aea5ad61e22a3dc79ede2de7b648fff841ff2684572af194b9c128
  tronweb hashMessage 와 비교: MATCH
  ethers.recoverAddress → T주소: TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH (MATCH)
  이더리움 프리픽스로 복원한 주소: TDHKsNC2AdETZKk2TrRaEMzbZL9zogLZha (MISMATCH)
  ✅ 트론 프리픽스로만 내 주소가 나옵니다. 프리픽스는 "이건 트랜잭션이 아니라 메시지다"라는 표시입니다.
  💬 digest = keccak256("\x19TRON Signed Message:\n" + byteLen + msg). ethers 로 재현 가능, EVM 프리픽스와는 다른 주소.

[4] 구조화 서명 (signTypedData, TIP-712) 과 chainId 검증

  types.Permit: owner:address, spender:address, value:uint256, deadline:uint256
  value: {"owner":"TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH","spender":"TSeJkUh4Qv67VNFwY8LaAxERygNdy6NQZK","value":"3000000","deadline":"1800000000"}
  서명: 0x925f1cb5…8ed3471c (0x + 130 hex)
  verifyTypedData(같은 domain): true
  verifyTypedData(chainId 바꿈) → 예외: Signature does not match
  ⚠️  verifyTypedData 는 불일치 시 false 가 아니라 예외를 던집니다. try/catch 가 필요합니다.
  ✅ 서명에 chainId(3448148188)가 묶여 있어 다른 나라(네트워크)에서는 재사용할 수 없습니다.
  💬 TIP-712 domain = { name, version, chainId, verifyingContract }. chainId/컨트랙트가 다르면 digest 가 달라져 검증 실패.

[5] TIP-712 해시가 EIP-712 해시와 같은지 확인 (ethers.TypedDataEncoder)
  ethers.TypedDataEncoder.hash (주소를 0x 로 바꿔 계산): 0xd52fa8a7731b13df7a6090a91249cdd42baaf55255b762254fa5df469df779e8
  그 해시 + tronweb 서명으로 복원한 주소: TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH (MATCH)
  ✅ tronweb signTypedData 와 ethers EIP-712 는 같은 해시에 서명합니다 (TIP-712 = EIP-712, 주소 표기만 다름).
  💬 검증 서버를 ethers 로 짜도 된다: T→0x 변환 후 TypedDataEncoder.hash + recoverAddress.
