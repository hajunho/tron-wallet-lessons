# Lesson 08 활동지 — 도장 검증 놀이

규칙 8: 무엇에 도장 찍는지 읽지 못하면 찍지 않는다.

## 오프라인 활동: 도장 검증 놀이 (20~25분, 4~8명)

### 준비물
- 도장 카드: 참가자 수만큼(각자 자기 "도장 무늬"를 그림). 무늬는 색깔 2개 + 모양 1개로 정해요. (예: 빨강 세모 + 파랑 점)
- 메시지 카드 12장: 아래 워크시트의 메시지를 한 장에 하나씩 적어요.
- 빈 카드 2장(여우 씨용).
- 색연필, 가위.

### 진행
1. **도장 만들기(5분)** — 각자 도장 카드에 자기 무늬를 그려요. 무늬는 친구들에게 보여 줘도 돼요. (우편함 번호처럼 공개해도 되는 것) 단, 무늬를 그리는 "손"은 나만 가지고 있어요. (열쇠)
2. **종이에 찍기(5분)** — 메시지 카드를 한 장씩 골라 내용을 읽고, 내 무늬를 그려 넣어요. 편지를 보내는 게 아니라 종이에 찍는 거라 우표(사탕)는 안 내요.
3. **누구 도장일까(5분)** — 카드를 섞어요. 한 명씩 카드를 뽑아 "이 도장은 ○○ 것"이라고 맞혀요. 맞으면 검증 성공. 이때 진행자가 카드 한 장의 글자를 몰래 하나 고쳐 둡니다. 글자를 고친 카드는 "찍은 사람이 없는 카드"로 취급해요. (같은 도장이라도 내용이 바뀌면 남의 도장처럼 보인다)
4. **여우 씨 등장(5분)** — 진행자가 여우 씨가 되어 빈 카드를 내밀어요. "여기 하나만 더 찍어 줘, 내용은 나중에 내가 쓸게." 찍은 사람은 진행자가 그 카드에 "내 사탕통에서 다 꺼내 가도 됨"이라고 써서 보여 줘요. 찍지 않은 사람은 안전.
5. **정리(3분)** — 아래 발문으로 마무리해요.

### 발문 3개
1. 도장 무늬(주소)는 모두에게 보여 줬는데, 왜 다른 사람은 내 도장을 못 찍었나요?
2. 글자를 하나 고친 카드는 왜 "찍은 사람이 없는 카드"가 되었나요?
3. 빈 카드에 찍은 도장은 나중에 무엇이 될 수 있었나요? 그러면 어떤 규칙이 필요할까요?

## 무장비 5분 버전: "빈 종이에 사인해 줄래?"

1. 한 명이 여우 씨가 되어 옆 사람에게 말해요. "빈 종이에 이름만 써 줘. 내용은 내가 나중에 쓸게."
2. 옆 사람은 거절하는 말을 한 문장 만들어요. (예: "뭐라고 쓸 건지 먼저 보여 주세요.")
3. 여우 씨가 이번엔 내용이 적힌 종이를 내밀어요. "친구 A에게, 사탕 3알까지, 내일까지."
4. 받은 사람은 세 칸(누구에게 / 얼마까지 / 언제까지)을 소리 내어 읽고 "찍는다/안 찍는다"를 정해요.
5. 역할을 바꿔 한 바퀴 돌아요. 마지막에 다 같이 외쳐요. "읽지 못하면 찍지 않는다!"
