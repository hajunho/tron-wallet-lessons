# Lesson 02 퀴즈 — 열쇠에서 우편함 번호가 나와요

규칙 2: 주소는 모두에게, 열쇠는 아무에게도.

대상별 5문제씩. 정답과 해설은 맨 아래에 있습니다.

---

## 🧒 초등 (그림·상황 고르기)

**초1.** 토리가 친구에게 알려 줘도 되는 것은 무엇일까요?
① 열쇠 ② 우편함 번호 ③ 12단어 주문

**초2.** 열쇠를 특별한 기계에 넣었더니 우편함 번호가 나왔어요. 이번엔 우편함 번호를 넣으면 무엇이 나올까요?
① 열쇠가 나와요 ② 아무것도 안 나와요. 기계는 한쪽으로만 돌아요 ③ 사탕이 나와요

**초3.** 토리의 우편함 번호는 어떤 글자로 시작할까요?
① T ② 0 ③ 토

**초4.** 토리가 열쇠 한 글자만 바꿔서 기계에 넣었어요. 우편함 번호는 어떻게 될까요?
① 한 글자만 바뀌어요 ② 처음부터 끝까지 다 바뀌어요 ③ 똑같아요

**초5.** 여우 씨가 "네 우편함 번호를 보면 열쇠를 찾아 줄 수 있어" 해요. 맞는 말일까요?
① 맞아요. 번호로 열쇠를 찾을 수 있어요 ② 틀려요. 번호로 열쇠는 못 만들어요 ③ 여우 씨만 할 수 있어요

**중1.** 스크립트 [2]단계에서 개인키의 마지막 한 글자만 바꿨는데 주소 `TUEZ…YdH`가 `TCXe…xic`로 전부 달라졌습니다. 해시의 어떤 성질 때문인지 한 줄로 쓰세요.

**중3.** 같은 12단어인데 `m/44'/195'/0'/0/0`과 `m/44'/60'/0'/0/0`에서 다른 주소가 나옵니다. 지갑 앱을 바꿔 복구했더니 잔고가 0으로 보이는 친구에게 무엇을 먼저 확인하라고 하겠습니까?

**중4.** [6]단계에서 "11번째 글자를 바꾼 주소"는 `isAddress`가 false인데, "앞 3글자가 같은 주소"는 true입니다. 두 주소는 무엇이 다릅니까?

**중5.** T주소는 안쪽 첫 바이트가 0x41로 고정이라 T 다음 글자는 58종이 아니라 25종만 나옵니다. 그래서 앞 3글자(T 포함)가 같은 주소는 평균 약 25 × 58 ≈ 1,450번이면 나옵니다. 앞 4글자와 뒤 4글자를 모두 맞추려면 평균 몇 번이 필요한지 거듭제곱으로 쓰고, "앞 4·뒤 4만 확인"이 왜 위험한지 한 줄로 쓰세요.

## 💻 개발자 (출력 예측)

**개1.** 다음 코드의 출력은 몇 글자이고 앞 두 글자는 무엇입니까?
```js
console.log(TronWeb.address.toHex('TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH'));
```

**개2.** 다음 코드는 무엇을 출력합니까? (true/false/예외 중 하나와 이유)
```js
const hex = TronWeb.address.toHex('TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH');
console.log(TronWeb.address.fromHex(hex) === 'TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH');
```

**개3.** 데모 니모닉으로 아래를 실행하면 어떤 값이 나옵니까? 소문자로 비교했을 때 `TUEZ…` 주소의 hex(`41` 제외)와 같습니까?
```js
const { walletFromMnemonic, DEMO_MNEMONIC } = require('./lib/wallet');
console.log(walletFromMnemonic(DEMO_MNEMONIC, 0).evmAddress);
```

**개4.** 데모 니모닉으로 다음 코드를 실행하면 무엇이 출력됩니까?
```js
const me = walletFromMnemonic(DEMO_MNEMONIC, 0);
const hex41 = TronWeb.address.toHex(me.address);        // 41c8599111f29c1e1e061265b4af93ea1f274ad78a
console.log('0x' + hex41.slice(2) === me.evmAddress);   // evmAddress = 0xC8599111F29c1e1E061265b4AF93eA1F274aD78A
```
① `true` ② `false` ③ 예외

**개5.** 스크립트의 닮은 주소 찾기를 `prefixLen = 4`로 바꾸면 평균 시도 횟수는 대략 몇 배가 됩니까? 그리고 이 반복은 왜 `walletFromMnemonic`이 아니라 `tiny-secp256k1`의 `pointFromScalar`로 구현했을까요?

## 정답과 해설

### 🧒 초등
- **초1. ②** 우편함 번호(주소)는 친구 모두에게 알려 줘도 돼요. 열쇠와 12단어 주문은 아무에게도 안 돼요.
- **초2. ②** 기계(해시)는 한쪽으로만 돌아요. 번호를 넣어도 열쇠는 안 나와요.
- **초3. ①** 트론 마을 우편함 번호는 T로 시작해요. 옆 나라(BTTC) 번호는 0x로 시작해요.
- **초4. ②** 한 글자만 달라도 번호가 처음부터 끝까지 달라져요. 스크립트에서 `TUEZ…`가 `TCXe…`로 바뀌었어요.
- **초5. ②** 번호로 열쇠를 만드는 방법은 없어요. 그렇게 말하는 사람은 여우 씨예요.

### 🔍 중고등
- **중1.** 해시는 입력이 1비트만 달라도 출력이 완전히 달라지는 성질(눈사태 효과)이 있고, 개인키→공개키 계산도 마찬가지로 작은 차이가 전체로 퍼지기 때문입니다.
- **중2.** `41`은 "이 주소는 트론 주소"라는 표시(프리픽스)이고, 체크섬 4바이트는 21바이트를 sha256 두 번 한 값의 앞부분이라 한 글자 오타를 잡아 줍니다(`isAddress` false).
- **중3.** 12단어가 틀린 것이 아니라 경로(coin_type 195' vs 60' 등)가 다를 수 있으니, 앱이 어떤 경로를 쓰는지 먼저 확인합니다. 스크립트 [5]단계가 그 차이를 보여 줍니다.
- **중4.** 오타 주소는 체크섬이 맞지 않아 "존재하지 않는 주소"이지만, 닮은 주소는 다른 열쇠에서 정상적으로 만들어진 "진짜 주소"라 체크섬이 맞습니다. 체크섬은 실수를 잡지 고의는 못 잡습니다.
- **중5.** T는 고정이므로 실제로 맞출 글자는 7개이고, 그중 첫 글자(T 다음)는 25종뿐이므로 평균 약 25 × 58^6 ≈ 9.5×10^11번입니다. 사람이 손으로 하기엔 크지만 컴퓨터가 오래 돌면 가능한 범위라, 앞뒤만 같은 주소를 만들어 끼워 넣는 사기(주소 오염)가 가능합니다.

### 💻 개발자
- **개1.** 42글자, 앞 두 글자 `41`. 출력은 `41c8599111f29c1e1e061265b4af93ea1f274ad78a` (스크립트 [3]단계).
- **개2.** `true`. `toHex`와 `fromHex`는 서로 역변환이라 원래 T주소로 돌아옵니다.
- **개3.** `0xC8599111F29c1e1E061265b4AF93eA1F274aD78A`. 소문자로 비교하면 `41` 뒤 40글자 `c8599111…274ad78a`와 같습니다.
- **개4. ②** `false`. 20바이트는 같지만 `toHex`는 소문자 hex, `evmAddress`는 ethers가 만드는 대소문자 섞인 체크섬 표기(EIP-55, 확인 필요)라 문자열이 다릅니다. `toLowerCase()`로 맞추거나 `ethers.getAddress('0x' + hex41.slice(2))`로 체크섬 형태를 만들어 비교해야 합니다(README "함정 1개", 스크립트 [3]단계).
- **개5.** 4번째 글자는 25종 제약이 없는 온전한 58종이므로 **약 58배**, 즉 평균 약 25 × 58^2 ≈ 84,100번입니다(앞 3글자 평균 1,450번의 58배). `walletFromMnemonic`은 니모닉→시드→HD 파생을 매번 다시 하므로 훨씬 느리고, 닮은 주소는 니모닉이 필요 없이 아무 32바이트 열쇠면 되기 때문에 `pointFromScalar`(개인키→공개키)만으로 충분합니다.

### 🏠 일반인
- **일1.** 됩니다. 주소는 공개해도 되는 값입니다. 다만 상대가 보낼 때 전체를 비교하도록 QR이나 전체 문자열을 함께 보내세요.
- **일2.** 입력하지 마세요. 12단어는 주소가 아니라 열쇠입니다. 어떤 고객센터도 열쇠를 묻지 않습니다(규칙 1·2). 채팅을 닫고 공식 앱 안의 고객센터로만 연락하세요.
- **일3.** 안 됩니다. 앞뒤가 같아도 가운데가 다른 "진짜" 주소를 사기꾼이 만들어 내역에 끼워 넣을 수 있습니다(주소 오염). 전체를 비교하거나 주소록·QR을 쓰세요.
- **일4.** 불가능합니다. 주소에서 개인키로 가는 계산은 존재하지 않습니다. 그런 광고는 사기이며, 대개 12단어를 입력하게 만드는 것이 목적입니다.
- **일5.** 12단어가 틀린 것이 아닐 수 있습니다. 앱마다 쓰는 경로가 달라서 같은 12단어로도 다른 주소가 나옵니다. 앱의 경로 설정을 먼저 확인하고, 원래 앱의 주소와 새 앱의 주소를 비교하세요.
