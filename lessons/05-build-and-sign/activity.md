# Lesson 05 활동 — 봉투 양식 채우고 검사받기

규칙 5: 도장을 찍기 전에 봉투(트랜잭션 내용)를 끝까지 읽는다.

이 활동은 초등(3~6학년)과 중고등 모두에 맞춰져 있습니다. 초등은 "받는 사람·사탕 수·유효기간" 세 칸만, 중고등은 아래 워크시트의 "장부 참조·봉투 번호" 칸까지 씁니다.

## 1. 오프라인 활동 (20~30분)

### 준비물
- 인쇄한 **트론 마을 봉투 워크시트**(아래 3절) — 한 사람당 3장(한 장은 일부러 틀리게 쓸 것이므로 넉넉히).
- 연필, 지우개(지우개는 **도장 전까지만** 쓸 수 있다는 규칙을 미리 알린다).
- 도장 대신 쓸 것: 스티커, 색연필로 그리는 동그라미, 또는 지문 스탬프.
- 초시계 또는 교실 시계(유효기간 60초 체험용).
- 우편함 번호 카드: 사람마다 한 장씩, `T`로 시작하는 34글자 번호. 실제 값을 쓰려면 아래 두 개(공개된 데모 주소)를 복사해 나눠 준다.
  - `TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH`
  - `TSeJkUh4Qv67VNFwY8LaAxERygNdy6NQZK`

### 진행
1. **역할 정하기(3분).** 둘씩 짝을 짓는다. 한 명은 **보내는 사람**, 한 명은 **검사관**. 나중에 바꾼다. 교사(또는 부모)는 **여우 씨**를 맡는다.
2. **봉투 쓰기(5분).** 보내는 사람은 워크시트의 봉투 양식에 받는 사람 우편함 번호(짝의 카드에서 그대로 베껴 쓰기), 사탕 수, 유효기간(60초)을 적는다. 쓴 순간 초시계를 켠다.
3. **끝까지 읽기(3분).** 검사관은 봉투를 받아 세 칸을 **소리 내어** 읽는다. 우편함 번호는 앞 4글자·뒤 4글자만이 아니라 **한 글자씩 전부** 카드와 대조한다. 하나라도 다르면 "반송!"이라고 말하고 돌려준다. 돌려받은 봉투는 도장 전이므로 지우개로 고칠 수 있다.
4. **도장 찍기(1분).** 검사를 통과하면 보내는 사람이 도장 칸에 스티커를 붙인다. 이 순간부터 **지우개 금지**. 고치고 싶으면 새 워크시트로 처음부터 다시 쓴다.
5. **유효기간 체험(2분).** 초시계가 60초를 넘긴 봉투는 검사에 통과했어도 "만료" 칸에 표시한다. 만료된 봉투는 버리고 새로 쓴다. 손해는 없다는 점을 강조한다(사탕은 아직 아무 데도 안 갔다).
6. **여우 씨 등장(5분).** 교사가 여우 씨가 되어 "시간 없어! 도장부터 찍어! 내가 읽어 줬으니까 안 읽어도 돼!" 하고 재촉한다. 몇 명이 안 읽고 찍는지 세어 본다. 그 뒤 재촉당한 봉투를 함께 읽어 틀린 곳을 찾는다(교사가 일부러 카드와 다른 번호를 불러 준다).
7. **역할 바꾸기(5분).** 보내는 사람과 검사관을 바꿔 2~6을 한 번 더 한다.
8. **마무리(3분).** "도장 찍은 봉투는 왜 못 고칠까?"를 이야기하고, 다음 레슨에서 이 봉투를 **우체통에 넣으면** 무슨 일이 생기는지 예고한다(넣으면 되돌릴 수 없다).

중고등 확장: 워크시트의 "장부 참조" 칸에 교사가 칠판에 적어 둔 최근 장 번호(예: 오늘 날짜 뒤 두 자리)를 적고, "봉투 번호" 칸에는 세 칸 내용을 한 줄로 이어 쓴 뒤 글자 수를 세어 적는다(해시 흉내). 한 글자를 고치면 봉투 번호도 다시 세어야 함을 체험한다. 실제 값은 `npm run l05` 출력의 `ref_block_bytes`와 `txID`로 확인한다.

### 발문 3개
1. 도장을 찍은 뒤에 사탕 수가 틀린 걸 알았어요. 그 봉투를 고칠 수 있나요? 어떻게 해야 하나요? (기대 답: 못 고친다. 새 봉투를 쓴다. 아직 우체통에 안 넣었으니 손해는 없다.)
2. 검사관은 왜 우편함 번호를 앞 4글자·뒤 4글자만 보지 않고 전부 읽었을까요? (기대 답: 가운데가 다른 "닮은 번호"가 있을 수 있어서. 레슨 2 복습.)
3. 여우 씨가 "내가 읽어 줬으니 안 읽어도 돼"라고 했어요. 그래도 내가 읽어야 하는 이유는? (기대 답: 도장은 내 것이고, 찍으면 내가 책임진다. 남이 읽어 준 내용과 봉투 내용이 다를 수 있다.)

## 2. 무장비 5분 버전

종이도 연필도 없을 때 말로만 한다.

1. 셋이 한 조. 순서대로 **보내는 사람 → 검사관 → 여우 씨**.
2. 보내는 사람이 봉투를 말한다. "받는 사람 ○○, 사탕 3알, 60초."
3. 검사관이 똑같이 따라 말한다. 세 칸이 모두 같으면 "도장!"이라고 외친다. 하나라도 빠지거나 다르면 "반송!"이라고 외치고 2로 돌아간다.
4. 여우 씨는 2와 3 사이에 "빨리빨리!", "안 읽어도 돼!"라고 방해한다. 검사관이 방해에 넘어가 안 읽고 "도장!"을 외치면, 여우 씨가 "사탕 30알이었지?" 하고 슬쩍 바꿔 말해 본다. 검사관이 "아니, 3알!" 하고 잡아내면 검사관 승리.
5. 역할을 한 바퀴 돌린다. 마지막에 다 같이 규칙 5를 소리 내어 읽는다.

## 3. 인쇄용 워크시트

아래를 그대로 인쇄하거나 칠판에 옮겨 그린다. 초등은 굵은 테두리 안 세 칸과 도장 칸만 쓴다.

### 트론 마을 봉투 (연습 나라 전용)

```
┌──────────────────────────────────────────────────────────────┐
│  트론 마을 봉투                          연습 나라(Nile) 전용  │
├──────────────────────────────────────────────────────────────┤
│  보내는 사람 우편함 번호            (T + 밑줄 33칸 = 34글자)  │
│  T _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _   │
├──────────────────────────────────────────────────────────────┤
│  받는 사람 우편함 번호   (카드와 한 글자씩 대조! 모두 34글자)  │
│  T _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _ _   │
├──────────────────────────────────────────────────────────────┤
│  사탕 수                  ______ 알   (사탕상자 1개 = 100만 알) │
├──────────────────────────────────────────────────────────────┤
│  유효기간                 쓴 시각 ____:____  + 60초 = ____:____ │
├──────────────────────────────────────────────────────────────┤
│  (중고등) 장부 참조        최근 장 번호 ____________             │
│  (중고등) 봉투 번호        세 칸을 이어 쓴 글자 수 ______ 글자   │
├──────────────────────────────────────────────────────────────┤
│  검사관 확인   받는 사람 [ ]  사탕 수 [ ]  유효기간 [ ]          │
│                검사관 이름 ____________   결과  통과 / 반송     │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   도장 칸 (검사 통과 후에만!  찍은 뒤에는 지우개 금지)          │
│                                                              │
│   [                    ]        만료됨 [ ]                    │
└──────────────────────────────────────────────────────────────┘
```

### 검사관 점검표 (봉투 1장마다 1줄)

| 봉투 번호(순서) | 받는 사람 번호 전부 일치? | 사탕 수 맞음? | 60초 안? | 도장 전에 고친 곳 | 결과(통과/반송/만료) |
|---|---|---|---|---|---|
| 1 | 예 / 아니오 | 예 / 아니오 | 예 / 아니오 | | |
| 2 | 예 / 아니오 | 예 / 아니오 | 예 / 아니오 | | |
| 3 | 예 / 아니오 | 예 / 아니오 | 예 / 아니오 | | |

### 여우 씨 방해 기록 (교사용)

| 여우 씨가 한 말 | 안 읽고 찍은 사람 수 | 그 봉투에서 틀린 칸 |
|---|---|---|
| "시간 없어, 빨리 찍어!" | | |
| "내가 읽어 줬으니 안 읽어도 돼" | | |
| "숫자 하나쯤은 괜찮아" | | |

### 빈칸 채우기 (마무리용)

1. 봉투 번호는 도장을 찍기 (전 / 후)에 정해진다.
2. 봉투 내용을 한 글자 고치면 봉투 번호는 (그대로다 / 바뀐다).
3. 트론 봉투의 기본 유효기간은 ______초다.
4. 도장은 (아무 봉투에나 / 이 봉투에만) 맞는다.
5. 도장을 찍은 봉투를 고치려면 (도장 위에 덧쓴다 / 새 봉투를 쓴다).

정답: 1 전 · 2 바뀐다 · 3 60 · 4 이 봉투에만 · 5 새 봉투를 쓴다

### 실제 봉투와 견주어 보기 (중고등·교사용)

`npm run l05`를 실행하면 `[2]` 단계에 실제 봉투의 칸들이 나온다. 워크시트 칸과 짝지어 보자.

| 워크시트 칸 | 실제 출력 줄 |
|---|---|
| 보내는 사람 우편함 번호 | `owner_address (hex41): 41c859… → TUEZSdKsoDHQMeZwihtdoBiN46zxhGWYdH` |
| 받는 사람 우편함 번호 | `to_address (hex41): 41b6e7… → TSeJkUh4Qv67VNFwY8LaAxERygNdy6NQZK` |
| 사탕 수 | `amount (sun): 1000000 = 1 TRX` |
| 유효기간 | `expiration: … (timestamp + 60초)` |
| 장부 참조 | `ref_block_bytes / ref_block_hash: …` |
| 봉투 번호 | `[3] txID (노드가 준 값): …` |
| 도장 칸 | `[6] signature[0]: … (130 hex = 65 bytes)` |
