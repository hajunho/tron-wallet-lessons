# Lesson 11 활동지 — "나라 맞추기" 카드 놀이

규칙 11: 보내기 전에 나라(네트워크)를 상대와 글자까지 맞춘다.

## 1. 오프라인 활동 (20~25분, 4~6명 한 모둠)

### 준비물
- 나라 카드 3장(아래 인쇄용): **TRON** / **BTTC** / **다른 나라**
- 우편함 번호 카드 12장(아래 인쇄용을 잘라서 사용)
- 옆 나라 봉투 워크시트 모둠당 4장
- 색연필 2색(T 모양용, 0x 모양용)
- 열쇠 모양 종이 1장(토리의 열쇠)

### 역할
| 역할 | 인원 | 하는 일 |
|---|---|---|
| 토리 | 1 | 열쇠 종이를 들고, 번호 카드를 뽑아 나라 카드 위에 올린다 |
| 비티 | 1 | "봉투에 나라 이름 썼어? 글자까지 똑같이!"만 말한다. 정답은 알려 주지 않는다 |
| 장부지기 | 2 | TRON 장부와 BTTC 장부를 한 장씩 들고, 자기 나라로 온 봉투만 적는다 |
| 여우 씨(선택) | 1 | "0x 면 다 같은 나라야, 그냥 보내"라고만 말한다. 손은 안 댄다 |

### 진행
1. **모양으로 나누기(5분).** 토리가 번호 카드를 한 장씩 뽑아 읽습니다. T로 시작하고 34글자면 TRON 카드 위에, 0x로 시작하고 42글자면 일단 BTTC 카드 위에 올립니다. 진행자는 정답을 말하지 않습니다.
2. **뒤집어 보기(5분).** 0x 카드를 뒤집으면 뒷면에 나라 이름이 적혀 있습니다. 어떤 카드는 "BTTC", 어떤 카드는 "다른 나라"입니다. 모양이 같은데 나라가 다른 카드를 "다른 나라" 카드로 옮깁니다. 진행자가 묻습니다: "앞면만 보고 나라를 알 수 있었나요?" (없다. 0x 모양은 여러 나라가 같이 쓴다.)
3. **같은 열쇠 찾기(5분).** 카드 중 토리의 T 번호(`TUEZ…YdH`)와 0x 번호(`0xC859…D78A`)가 한 쌍입니다. 토리가 열쇠 종이를 두 카드 위에 번갈아 올리며 "둘 다 내 우편함!" 하고 말합니다. 장부지기 두 명은 각자 장부에 토리 우편함을 적되, 사탕 수는 나라마다 따로 적습니다(TRON 장부: 사탕상자, BTTC 장부: 0개). "열쇠가 같으면 사탕도 같이 있나요?" (아니요. 장부가 따로다.)
4. **봉투 쓰기(5분).** 토리가 옆 나라 봉투 워크시트에 받는 사람 0x 번호, 나라 이름, 순서 번호(0부터), 우표 칸을 채웁니다. 나라 이름 칸을 비우면 장부지기 둘 다 "우리 나라 봉투 아님" 하고 돌려줍니다. 여우 씨가 "0x 면 다 같아, 그냥 넣어"라고 해도 토리는 나라 이름을 씁니다.
5. **정리(3분).** 발문 3개.

### 발문 3개
1. 토리 열쇠 하나로 두 나라 우편함이 다 열렸어요. 그러면 두 나라 사탕도 같은 통에 있을까요? (아니요. 장부가 나라마다 따로 있어서 사탕도 따로예요.)
2. 0x로 시작하는 번호만 보고 "옆 나라 BTTC"라고 말해도 될까요? (안 돼요. 0x 모양을 쓰는 나라가 여럿이라 봉투의 나라 이름을 봐야 해요.)
3. 옆 나라 봉투에는 순서 번호(nonce)를 써요. 트론 마을 봉투에는 무엇이 있었나요? (유효기간 60초. 옆 나라 봉투엔 유효기간이 없어요.)

## 2. 무장비 5분 버전 — "나라 이름 외치기"

1. 모두 일어섭니다. 진행자가 주소 모양을 말합니다.
2. "T로 시작, 34글자!" → 모두 "트론!" 하고 외칩니다.
3. "0x로 시작, 42글자!" → 모두 "어느 나라?" 하고 되묻습니다. 바로 "BTTC!"라고 외친 사람은 한 판 앉아서 쉽니다.
4. 진행자가 "봉투에 BTTC 라고 써 있어" 하면 그제야 "BTTC!" / "봉투에 다른 나라라고 써 있어" 하면 "다른 나라!"
5. 다섯 번 반복하고, 마지막에 "왜 0x만 듣고는 나라를 못 맞췄을까?"를 한 사람씩 말합니다.

## 3. 인쇄용 워크시트

### (가) 나라 카드 3장 (잘라서 책상에 놓기)

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│    TRON      │  │    BTTC      │  │  다른 나라    │
│  트론 마을    │  │  옆 나라      │  │  (0x 모양)    │
│  T… 34글자   │  │  0x… 42글자  │  │  0x… 42글자  │
│  chainId     │  │  chainId     │  │  chainId     │
│  344814…     │  │  1029        │  │  ?           │
└──────────────┘  └──────────────┘  └──────────────┘
```

TRON 카드의 chainId 는 `3448148188` (Nile 테스트넷 값, 카드 폭이 좁아 `344814…` 로 줄였습니다). "다른 나라" 카드의 `?` 는 그대로 둡니다 — "모양은 같은데 번호는 모른다"를 두 카드로 대비시키는 것이 이 활동의 핵심입니다.

| 3 | `TSeJkUh4Qv67VNFwY8LaAxERygNdy6NQZK` | TRON (index 1 우편함) |
| 4 | `0xb6E708a39781c96Bd399C7657780Ff9Fe9F052A8` | BTTC (index 1 우편함, 3번과 같은 열쇠) |

| 11 | `0xf4f35FFF5Ca9Ee43ACa2c57DED9d9EC66ac42Dd0` | BTTC (index 2 우편함, 10번과 같은 열쇠) |

### (다) 옆 나라 봉투 — 나라 이름을 꼭 쓰기

```
┌─────────────────────────────────────────────┐
│  옆 나라 봉투                                 │
│                                             │
│  보내는 사람: 0x_______________________       │
│  받는 사람:   0x_______________________       │
│  사탕 수:     ______ BTT                     │
│  나라 이름:   ____________  (글자까지 똑같이) │
│  순서 번호:   ______  (지금까지 보낸 수)      │
│  우표:        ______ gas × ______ 값         │
│  유효기간:    없음 (순서 번호가 대신함)        │
│                                             │
│  읽었어요 체크                                │
│   [ ] 나라 이름을 상대와 맞췄어요              │
│   [ ] 0x 모양만 보고 나라를 정하지 않았어요     │
│   [ ] 처음이면 아주 조금만 보내요              │
│                                             │
│  도장(서명) 칸:  ┌────────┐                   │
│                 │        │                   │
│                 └────────┘                   │
└─────────────────────────────────────────────┘
```

### (라) 빈칸 점검표

| 질문 | 답 |

| 같은 열쇠라도 나라마다 장부가 ( 같다 / 따로다 ). | |
| 옆 나라 봉투에는 유효기간 대신 ( )를 쓴다. | |

| "0x 면 아무 나라로 보내도 돼"라고 말하는 사람은 ( )이다. | |
